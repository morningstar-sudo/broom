Drivers

custom Windows drivers installed into each machine's base

Upload a driver package (.zip)

The zip must contain the extracted driver (.inf + .sys + .cat…), not the vendor's .exe installer (extract it first, e.g. open the NVIDIA/AMD installer with 7-Zip). Same name again = replace the package.

A machine gets a package when one of its devices matches a hardware ID, the package is assigned to its group (Machines page), or All machines is ticked. Changes apply on each machine's next boot: the stage downloads the packages and rebuilds its base once (Windows installs the drivers that match its devices). Windows images only.
