A machine is in one group (or none). It gets the images, games disks and driver packages of its group plus those for every machine (last row). Names: letters / digits / _ / -, at most 32. An image or games disk for every machine is limited to groups on its own page (Images); one that would lose its last group here asks first — it would then go to every machine. Changes apply at each machine's next boot.
