DHCP + PXE + reset policy

DHCP settings

Off (default): the LAN's DHCP server (router) hands out IPs. Point its PXE options here: next-server / option 66 = this server, boot file / option 67 = snponly.efi (Secure Boot clients: sb/snponly-shim.efi). broom serves iPXE over TFTP and the menu over HTTP.
On: this server hands out IPs + PXE boot info on that interface — turn off any other DHCP server on the LAN first; gateway and DNS are required.

Strict reset: the SSD's Windows boot entries are kept out of the boot order and Windows removes its boot loader from the SSD after each start, so a machine reaches Windows ONLY through PXE (every session reset). Server or network down = the machines don't start Windows. Off: they still boot from the SSD (that session not reset; the Machines page flags it).
