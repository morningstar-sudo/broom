User café (Linux)

User café = tên duy nhất được login. Mỗi boot XOÁ HẾT user trong image (uid≥1000) rồi tạo lại user café fresh (home skel). Password đặt ở đây.
Autologin vào desktop, home tạo mỗi boot (fresh), game ghi xuống SSD. Đổi xong áp dụng → reboot máy. Cũng ghi hostname các máy đã đăng ký.
SSD device: auto = ổ vật lý đầu tiên (bất kể sda/nvme, hợp máy 1 ổ), hoặc gõ /dev/sda. Cache SSD: off (đọc NFS) / SSD local (cache golden, boot nhanh). ⚠ Bật SSD cache repartition ổ (xoá /games cũ). (LTSP cũ — gỡ ở B6 sau PoC iSCSI.)
