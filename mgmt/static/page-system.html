Admin password

Changing the password signs out every other browser (all old sessions stop working). This one stays signed in.

Guest user (Windows)

The user is created + set to autologon in the Windows golden when the Windows prep command (Images page) runs in the VM. Changes here only apply to goldens prepared afterwards (run prep again → upload). Linux golden: the user already exists in the image.

Countdown boot menu

seconds

zram — RAM reserved for the server

MB

Loading a golden into zram (compressed RAM cache) is refused if img + reserve > available RAM → avoids RAM overflow/OOM. Reserve = RAM kept for the OS + iSCSI serving. Not enough → the image falls back to disk by itself.
