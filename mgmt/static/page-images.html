Golden Linux (.zip từ ltsp-script)

Trên VM desktop: curl -fsSL http://SERVER/ltsp-script | sudo bash → /tmp/golden.zip → upload ở đây (server tự giải nén + publish).

Golden (.vmdk / .img / .zip) — iSCSI + overlay SSD

Bake overlay trong golden VM trước: curl -fsSL http://SERVER/broom-prep | sudo bash → tắt VM. Up 1 file vmdk monolithic (VMware chẻ nhiều file: vmware-vdiskmanager -r disk.vmdk -t 0 golden.vmdk) HOẶC zip cả folder VM (mọi .vmdk) → server tự chọn descriptor + convert. Đừng up từng extent lẻ. disk = rẻ; zram = img hot lên RAM (nén).
