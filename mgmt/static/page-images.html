Golden (VM folder / .vmdk / .img / .zip) — iSCSI + overlay SSD

Power the VM off, then pick its whole folder — no zip needed (only .vmx/.vmdk are sent; memory files are skipped).

Disks on the server for the Windows machines (Steam / launcher libraries go there); a machine gets every disk of its group (Devices page) plus those set for all machines, each under its drive letter. Guests write to their own SSD (thrown away at reboot); a games disk itself never changes. To install / update games: pick the disk's update machine → (re)boot it: that drive is writable there → install → shut it down properly → Save: a new version at once — each machine gets it at its next boot, machines already playing keep theirs. A new disk is set up (formatted) by its first update machine. Size can only grow; the update machine extends the drive on its next boot. Two disks the same machine gets need different letters.
